CORE SYSTEM INVARIANTS (MUST PRESERVE AT ALL COSTS)
--------------------------------------------------------------------------------
1. EXACT INTEGER CENTS FINANCIAL ENGINE:
   - All currency values (prices, costs, commissions, taxes, totals) MUST be stored 
     and calculated as integers in the smallest currency unit (e.g. cents/paisa: 
     Rs. 1,500.00 = 150000). Never use floating-point numbers for money.
   - Tax rates and percentage commissions are stored in basis points (1% = 100 bp).

2. DYNAMIC APPEND-ONLY STOCK LEDGER:
   - Never add a static `quantity_on_hand` column to `inventory_items`. Stock is 
     always dynamically computed from `stock_movements`.

3. NON-DESTRUCTIVE SOFT DELETES:
   - Never use SQL `DELETE` on operational data. Always update `is_active = 0`.

4. STRICT IPC PROCESS ISOLATION:
   - React components NEVER import Node.js or SQLite directly. All backend calls 
     flow through typed IPC channels exposed on `window.api`.

5. 100% OFFLINE-FIRST CAPABILITY:
   - If external network services (SMS, cloud sync) are unavailable, the application 
     MUST gracefully log the failure, continue offline operations, and never freeze.

DATABASE MIGRATION SPECIFICATION (009_advanced_features.sql)
--------------------------------------------------------------------------------
Create `src/main/database/migrations/009_advanced_features.sql`:

```sql
-- Migration 009: Commission rules, Damage markers, and Notification logs
ALTER TABLE services ADD COLUMN commission_type TEXT NOT NULL DEFAULT 'default';
ALTER TABLE services ADD COLUMN commission_value INTEGER NOT NULL DEFAULT 0;

ALTER TABLE job_cards ADD COLUMN damage_markers TEXT;

CREATE TABLE IF NOT EXISTS notification_logs (
  id TEXT PRIMARY KEY,
  channel TEXT NOT NULL, -- 'sms', 'whatsapp'
  recipient TEXT NOT NULL,
  message TEXT NOT NULL,
  status TEXT NOT NULL, -- 'sent', 'failed', 'queued'
  reference_type TEXT, -- 'job_card', 'invoice', 'reminder'
  reference_id TEXT,
  error_message TEXT,
  created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_notifications_ref ON notification_logs(reference_type, reference_id);
CREATE INDEX IF NOT EXISTS idx_notifications_created ON notification_logs(created_at);
```
